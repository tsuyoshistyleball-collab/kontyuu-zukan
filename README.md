# 🪲 むしずかん (Mushi Zukan) — こども むけ AI こんちゅう ずかんアプリ

4さいの こども むけの「昆虫図鑑」PWA アプリです。
みつけた むしの **しゃしんを とると、AI（Gemini）が むしを すいそくして なまえを つけ**、
じぶんだけの ずかんに どんどん とうろく されていきます。
なまえは あとから **てで なおす** ことも できます。

## ✨ とくちょう

- **ずかんの きりかえ（🐛むし / 🌸おはな）** — タイトルを タップで きりかえ。データ・レベル・なかまわけ・AIの すいそくは それぞれ べつべつ、いった ばしょは きょうつう
- **しゃしん → AIすいそく → とうろく** — Gemini（`gemini-3.1-flash-lite`）が がぞうから むしを みわけ、なまえ・ひとこと・レアど・なかまわけ を すいそく
- **なまえは しゅうせいできる** — AIの すいそくが ちがっても、てで かきなおせる
- **カメラ ＆ ファイル りょうほう** — その ばで さつえい、または アルバム/ファイルから アップロード
- **じどう カテゴリーわけ** — こうちゅう・ちょう・とんぼ・せみ・ばった・はち/あり・くも・かたつむり など、しゅるいごとに じどうで せいり
- **ページ形式の ずかん（ブック）** — 📖 よこに めくって 1ぴきずつ じっくり みられる。いちらん ページから カードを タップしても ひらく
- **コレクション かん** — あつめた しゅるいの かず、レアど（★1〜3）、はっけんの おいわい えんしゅつ（こんぺいとう・おと・しんどう）
- **なんども とれる** — おなじ むしを なんまいでも。ギャラリーで みなおせる
- **ひょうしの しゃしんを えらべる** — ギャラリーの ★を タップすると、その しゃしんが カードの ひょうしに なる
- **じどう バックアップ** — とうろくの あと 6じかんに 1かい、ぜんぶの ずかんを 1つの ファイルに ほぞん（せっていで オフに できる）
- **やさしい ひらがな** — 4さいでも よめる。おおきくて まるい ボタン
- **オフライン対応 / ホーム画面インストール**（PWA）
- **しゃしんも APIキーも たんまつ内だけ** — IndexedDB / localStorage に ほぞん。がいぶには おくらない

## 🔑 Gemini API キーの せってい

AIで なまえを じどう にゅうりょく するには、Gemini の APIキーが ひつようです（むりょうわく あり）。

1. アプリ右上の **⚙️ せってい** を ひらく
2. **Google AI Studio**（https://aistudio.google.com/apikey）で APIキーを つくって コピー
3. せってい画面の「Gemini APIキー」に はりつけて **ほぞん**
4. モデルは **`gemini-3.1-flash-lite`** が しょきち（かえても OK）

> APIキーが なくても、なまえを **てで いれて** つかえます。

## 📱 インストール（PWA）

1. HTTPS で こうかい（GitHub Pages など）した URL を スマホの ブラウザで ひらく
2. メニューから **「ホーム画面に追加」**
3. ホームの 🪲アイコンから ぜんがめんで あそべる

> カメラを つかうには **HTTPS**（または `localhost`）が ひつようです。

### ローカルで ためす

```bash
python3 -m http.server 8000   # http://localhost:8000
```
