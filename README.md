# 🪲 むしずかん (Mushi Zukan) — こども むけ AI こんちゅう ずかんアプリ

4さいの こども むけの「昆虫図鑑」PWA アプリです。
みつけた むしの **しゃしんを とると、AI（Gemini）が むしを すいそくして なまえを つけ**、
じぶんだけの ずかんに どんどん とうろく されていきます。
なまえは あとから **てで なおす** ことも できます。

## ✨ とくちょう

- **ずかんの きりかえ（🐛むし / 🌸おはな）** — タイトルを タップで きりかえ。データ・レベル・なかまわけ・AIの すいそくは それぞれ べつべつ、いった ばしょは きょうつう
- **しゃしん → AIすいそく → とうろく** — Gemini（`gemini-3.1-flash-lite`）が がぞうから むしを みわけ、なまえ・ひとこと・レアど・なかまわけ を すいそく
- **なまえは しゅうせいできる** — AIの すいそくが ちがっても、てで かきなおせる
- **カメラ ＆ ファイル りょうほう** — その ばで さつえい、または アルバム/ファイルから アップロード
- **「科（か）」ごとの じどう 分類** — Gemini が 生物学の 科（クワガタムシ科・アゲハチョウ科・キク科 など）を 答え、それごとに 図鑑を 整理。科が わからない ものは おおまかな なかまわけ（こうちゅう・ちょう など）に まとまる
- **本(ほん)みたいに めくれる 図鑑** — 📖 革表紙・背表紙・小口つきの 本のデザイン。指で ドラッグすると 紙が 3Dで めくれ、めくる音も 鳴る
- **コレクション かん** — あつめた しゅるいの かず、レアど（★1〜5・レアどごとに カードの ひかりかたが かわる）、はっけんの おいわい えんしゅつ（こんぺいとう・おと・しんどう）
- **なんども とれる** — おなじ むしを なんまいでも。ギャラリーで みなおせる
- **くわしい ずかん じょうほう** — まめちしき3つ・すんで いる ところ（はえて いる ところ）・きせつ・おおきさ・たべもの（すきな ばしょ）・かいかた（そだてかた）。ずかんに ある 27しゅるいは オフラインでも よめる。ほかは 📖ページの「🤖 AIに くわしく きく」で しらべられる
- **たたかいの すうじ（バトルカード）** — とうろくの ときに AIが こうげき力・しゅび力（100〜900の 10きざみ）と じゃんけんの ぞくせい（グー/チョキ/パー）を きめる。おなじ しゅるいなら いつでも おなじ すうじ
- **ひょうしの しゃしんを えらべる** — ギャラリーの ★を タップすると、その しゃしんが カードの ひょうしに なる
- **じどう バックアップ** — とうろくの あと 1じかんに 1かいまで、ぜんぶの ずかんを 1つの ファイルに ほぞん（せっていで オフに できる）
- **漢字＋ふりがな（ルビ）** — 画面の 文章は 漢字を つかい、上に ふりがなを ふって 表示。読みやすく、漢字にも 慣れられる
- **やさしい ことば** — 4さいでも よめる。おおきくて まるい ボタン
- **オフライン対応 / ホーム画面インストール**（PWA）
- **しゃしんも APIキーも たんまつ内だけ** — IndexedDB / localStorage に ほぞん。がいぶには おくらない

## 🔑 Gemini API キーの せってい

AIで なまえを じどう にゅうりょく するには、Gemini の APIキーが ひつようです（むりょうわく あり）。

1. アプリ右上の **⚙️ せってい** を ひらく
2. **Google AI Studio**（https://aistudio.google.com/apikey）で APIキーを つくって コピー
3. せってい画面の「Gemini APIキー」に はりつけて **ほぞん**
4. モデルは **`gemini-3.1-flash-lite`** が しょきち（かえても OK）

> APIキーが なくても、なまえを **てで いれて** つかえます。

## 📱 機種変更・端末の引きつぎ

記録は**その端末のブラウザの中**にあります。スマホの OS が行う自動バックアップ（iCloud / Google One）には
**ブラウザの保存領域は含まれない**ため、機種変更で勝手に引きつがれることはありません。
そのかわり、1タップで持ち出せるようにしてあります。

1. 今のスマホで ⚙️設定 → **「📤 バックアップを ほかへ 送る」**
2. Google ドライブ・LINE・メールなど、好きなところへ送る（1タップ）
3. 新しいスマホでアプリを開き、**「📂 バックアップから 戻す」** でそのファイルを選ぶ

写真・場所・★・表紙まで、そのまま引きつがれます。
なお、むしを登録したあと**1時間に1回まで、自動でバックアップファイルが端末に保存**されるので、
何もしなくても最新に近いファイルが手元にあります（⚙️設定でオフにできます）。

## ☁️ 別の端末と つなぐ（Google ドライブ連携・任意）

**使わなくても大丈夫です。** この図鑑の記録は、もともと**その端末のブラウザの中だけ**にあります。
サーバーはないので、**別の人がこのアプリを開いても、その人の図鑑は完全に別物**です。データが混ざることはありません。

「同じ人が、スマホとタブレットの両方で続きをやりたい」「ブラウザのデータを消しても復元したい」ときだけ、
下の設定をすると Google ドライブ経由で同期できます。**5分ほどの初期設定が1回だけ**必要です。

保存先は、あなたの Google ドライブの中の**アプリ専用フォルダ**（`appDataFolder`）です。
ドライブの画面には出てこない隠し領域で、このアプリ以外からは読めません。

### 手順

1. <https://console.cloud.google.com/> を開いて Google でログイン
2. 画面上部でプロジェクトを新規作成（名前はなんでも OK。例: `mushizukan`）
3. 左メニュー **「APIとサービス」→「ライブラリ」** で `Google Drive API` を検索して **有効にする**
4. 左メニュー **「APIとサービス」→「OAuth 同意画面」**
   - User Type は **外部** を選んで作成
   - アプリ名・サポートメール・デベロッパー連絡先を入力（自分のメールで OK）
   - スコープは追加しなくてよい（アプリ側から要求します）
   - **テストユーザー**に自分の Google アカウントを追加
5. 左メニュー **「APIとサービス」→「認証情報」→「認証情報を作成」→「OAuth クライアント ID」**
   - アプリケーションの種類: **ウェブ アプリケーション**
   - **承認済みの JavaScript 生成元** に、アプリを公開している URL の**オリジン**を追加
     （例: `https://tsuyoshistyleball-collab.github.io`）
   - リダイレクト URI は不要
6. できた **クライアント ID**（`〜.apps.googleusercontent.com`）をコピー
7. アプリの **⚙️設定 →「☁️ 別の端末と つなぐ」** を開き、クライアント ID を貼り付けて **「🔑 Google で ログイン」**

これで、むしを登録するたびに自動でドライブへ送られます。
別の端末では、同じクライアント ID を入れて同じ Google アカウントでログインすれば、写真ごと復元されます。

### 同期のしくみ

- 写真は 1枚ずつ別ファイル。**新しい分だけ**送るので通信量は小さい
- 記録（名前・★・場所・表紙）は `meta.json` にまとまっている
- 両方にあるものは**足し算でマージ**するので、どちらの端末のデータも消えません
- 消したものは記録されるので、片方で消せばもう片方でも消えます

## 📱 インストール（PWA）

1. HTTPS で こうかい（GitHub Pages など）した URL を スマホの ブラウザで ひらく
2. メニューから **「ホーム画面に追加」**
3. ホームの 🪲アイコンから ぜんがめんで あそべる

> カメラを つかうには **HTTPS**（または `localhost`）が ひつようです。

### ローカルで ためす

```bash
python3 -m http.server 8000   # http://localhost:8000
```
