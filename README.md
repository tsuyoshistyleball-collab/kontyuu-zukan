# 🪲 むしずかん (Mushi Zukan) — こども むけ こんちゅう ずかんアプリ

4さいの こども むけの「昆虫図鑑」PWA アプリです。
ふだんの せいかつで みつけた むしを **しゃしんに とって ずかんに とうろく** し、
ポケモンを あつめる ように コレクションして いきます。

まだ みつけていない むしは **シルエット と「？」** で ひょうじされ、
「これ みつけたい！」という きもちを くすぐります。
みつけて しゃしんを とると、じぶんの しゃしんで カラーの カードが かんせいします。

## ✨ とくちょう

- **コレクション ずかん** — 18しゅるいの むし。あつめた かずが すすむと しんちょくバーが のびる
- **シルエット表示** — みつける まえは くろい かげ ＋「？」で ワクワク（レアどの ★ は みえる）
- **カメラ とうろく** — スマホの カメラで さつえい → その ばで ずかんに とうろく
- **レアど（★1〜3）** — かぶとむし・くわがた・かまきり・すずむし などは ★★★ の レア
- **おいわい えんしゅつ** — あたらしい むしを みつけると こんぺいとう ＋ ファンファーレ ＋ ぶるっと しんどう
- **なんども とれる** — おなじ むしを なんかいでも さつえい。ギャラリーで みなおせる
- **やさしい ひらがな** — 4さいでも よめる。おおきくて まるい ボタン
- **オフライン対応** — いちど ひらけば ネットが なくても つかえる（Service Worker）
- **ホームがめんに ついか** — インストールすると ふつうの アプリの ように ひらける
- **データは たんまつの なかだけ** — しゃしんは IndexedDB に ほぞん。がいぶには おくらない

## 📱 つかいかた（インストール）

このアプリは **PWA** なので、アプリストア なしで ホームがめんに おけます。

1. ファイルを ウェブサーバー（HTTPS）に おく、または GitHub Pages などで こうかいする
2. スマホの ブラウザ（Chrome / Safari）で ひらく
3. メニューから **「ホーム画面に追加」** を えらぶ
4. ホームがめんの アイコンから ぜんがめんで あそべる

> カメラを つかうには **HTTPS**（または `localhost`）が ひつようです。

### かんたんな ためしかた（ローカル）

```bash
# このフォルダで かんたんな サーバーを たてる
python3 -m http.server 8000
# ブラウザで http://localhost:8000 を ひらく
```

## 🗂 ファイルこうせい

```
index.html              がめんの ほんたい
css/style.css           デザイン（カラフル・まるい・こども むけ）
js/data.js              むしの データ（なまえ・レアど・ヒント・イラスト SVG）
js/db.js                しゃしんの ほぞん（IndexedDB）
js/app.js               アプリの うごき（ずかん・カメラ・おいわい）
manifest.webmanifest    PWA の せってい
service-worker.js       オフライン ようの キャッシュ
icons/                  アプリ アイコン（てんとうむし）
make_icons.py           アイコンを つくる スクリプト（Pillow）
```

## 🐛 むしを ふやすには

`js/data.js` の `INSECTS` はいれつに オブジェクトを ついかするだけです。

```js
{
  id: "kamemushi", name: "かめむし", kana: "カメムシ", stars: 2, color: "#7aa05a",
  where: "はっぱの うえ", fact: "さわると くさい においを だすよ。",
  svg: `<svg viewBox="0 0 120 120">...</svg>`
}
```

`svg` は カラーの イラストで、みつける まえは じどうで シルエットに なります。
